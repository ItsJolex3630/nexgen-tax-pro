# 💼 NexGen Tax Pro - Software, Training & Support

Repositorio oficial y de producción para el despliegue de **NexGen Tax Pro** en **Cloudflare Pages**.

## 🌐 Despliegue en Cloudflare Pages
- **Proyecto:** `nexgen-tax-pro`
- **Dominio Pages:** `https://nexgen-tax-pro.pages.dev`
- **Rama principal:** `main`

## 🔒 Reglas de Seguridad
- El archivo `.gitignore` protege rigurosamente cualquier variable de entorno (`.env*`).
- Ningún secret, token o credencial bancaria/fiscal debe subirse al repositorio.

## 📂 Contenido
- `index.html`: Landing page corporativa de alta conversión con presentación de software tributario, capacitación profesional y soporte para preparadores de impuestos.
- `wrangler.jsonc`: Configuración nativa para Cloudflare Pages.
